===========================================
NOTES & OBSERVATIONS
===========================================

1. Trigonometric functions work with radians by default (standard Math class behavior)
   - Users familiar with degrees may need to convert: degrees * π / 180

2. Parentheses support allows complex nested expressions
   - Example: sin(45) + cos(30) = valid expression

3. Constants append as decimal values (e.g., 3.14159265358979)
   - Automatically truncated to 10 significant digits in display

4. Scientific functions intelligently handle placement:
   - After an operator: appends directly
   - After a number: assumes multiplication
   - Example: "5sin(" is converted to "5*sin("

5. The power operator ^ is recognized and supported in expressions
